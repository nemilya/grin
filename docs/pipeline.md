# Пайплайн: рассказ → озвучка → видео → сайт

Описание процесса как контракта этапов: что на входе, что на выходе, чем запускается, как проверяется,
кто принимает решение. По нему же собирается будущий автоматический пайплайн (`make film S=…`, см. «Автоматизация»).
Пример везде — «Мат в три хода» (`stories/mate-in-3`) и постановка по Тарковскому (`stories/mate-in-3-tarkovsky`).

## Понятия

| | что это | где |
|---|---|---|
| **рассказ** | текст, перевод, озвучки по языкам | `stories/<рассказ>/` (`story.json`, `prepared/`, `translations/`, `voicings/`) |
| **постановка** | видео по рассказу в одном стиле: библия, раскадровка, ассеты | своя история с `"base": "<рассказ>"` или сам рассказ (первая постановка) |
| **стиль** | как рисуются картинки + параметры сцены | `styles/<стиль>.json` |
| **режиссёр** | киноязык: длины планов, камера, умолчания кадра | `directors/<имя>.json` (необязательно) |
| **формат** | вертикаль 9:16 (`film`), горизонталь 16:9 (`formats.horizontal` + `storyboard-16x9.json`) | `story.json` постановки |
| **язык ролика** | голос и субтитры; раскадровка одна (на языке перевода) | `film.voicings`, `make … L=ru` |

Связи: id абзацев (`story-018`) общие для всех языков; реплики раскадровки (`018.13+0.4`) ссылаются на предложения
языка раскадровки — для другого языка движок переносит их по доле текста абзаца, паузы — на ближайший промежуток
между предложениями. Поэтому одна раскадровка даёт ролики на всех языках.

## Этапы

Статусы и отпечатки — как в mountain-rock: у генерируемого есть отпечаток входов (текст, настройки, референсы);
поменялось что-то выше — ниже становится «устаревшим» (stale), остальное не трогается. Общая сводка — `make status`.

### 1. Текст — `make prepare`
- **вход:** `content/<рассказ>.txt`, `story.json → source` (`skip` — сколько первых блоков не озвучивать: автор и название);
- **выход:** `prepared/<язык>.json` — абзацы → предложения → слова (смещения в тексте);
- **проверка:** число абзацев; правка деления на предложения сдвигает реплики раскадровки — после неё сравнить
  число предложений в абзацах;
- **кто:** скрипт.

### 2. Глоссарий и перевод — `make translate`
- **вход:** `prepared/ru.json`, библия (имена);
- **выход:** `glossary.json`, `translations/en.json` (по абзацам, те же id), `prepared/en.json`;
- **цена:** ≈ $0.2 на рассказ такого размера (Opus через OpenRouter);
- **кто:** LLM; человек читает и правит перевод (JSON).

### 3. Озвучка — `make voice` (`L=ru` — другой язык)
- **вход:** `prepared/<язык>.json`, `voicings/<id>/voicing.json` (голос, модель, общая манера), `overrides/<язык>.json`
  (манера по абзацам: «шёпотом», «крик»);
- **выход:** `voicings/<id>/items/<абзац>.json` (дубли, оценка распознаванием, время слов), `takes/*.opus`;
- **проверка:** каждый дубль распознаётся обратно и сравнивается с текстом (score ≥ 0.9, конец фразы на месте),
  иначе — новый дубль; сбой провайдера (429, пустой звук) — абзац пропускается, повторный запуск доберёт;
- **цена:** ≈ $0.015 за минуту (TTS + распознавание), рассказ 15–19 мин ≈ $0.25;
- **кто:** скрипт; человек слушает (админка → «Озвучка»).

### 4. Библия постановки — `bible.json`
- **вход:** текст, стиль постановки;
- **выход:** мир, герои (канон внешности + позы), декорации (слои по глубине: задник, стена с проёмом, пол,
  предметы; позиции в см), предметы. Описания — по-английски и **без стиля**;
- **проверка:** `assets.plan` собирается; позы покрывают раскадровку (иначе `make timeline` — «нет ассета»);
- **кто:** сейчас агент (Claude Code) по навыку `storyboard`; дальше — LLM по схеме (см. «Автоматизация»).

### 5. Раскадровка — `storyboard.json` (+ `storyboard-16x9.json`)
- **вход:** текст с id предложений, библия, режиссёр;
- **выход:** сцены → кадры: реплика начала (`at`), камера (`cam`, `cam_to`, `push`, `drift`, `hand`), фокус, свет
  (пресеты, туман, цвет), элементы и их движение (`cast`), паузы (`holds`), звук (`sound`, `sfx`);
- **проверка:** `make timeline` — ошибки реплик, камер, ассетов валят команду; предупреждения режиссёра (короткие
  планы); стоп-кадры `node tools/capture.mjs stills <постановка> --scale 0.3` и лист `out/<постановка>/stills/contact.jpg`
  (`--debug` — ровный свет, видна композиция); то же для `F=horizontal`;
- **кто:** агент или LLM + валидатор; человек смотрит лист кадров.

### 6. Ассеты — `make assets-used` (или `python3 -m engine assets <постановка>`)
- **вход:** библия, стиль, листы героев;
- **выход:** `assets/` — сначала листы героев (разворот из 4 видов — референс для всех поз), затем позы, декорации,
  предметы; ключ хромакея → WebP без потерь с прозрачностью (стиль `key: soft` — мягкий край «кино»); `assets.json` — отпечатки, seed, цена;
- **проверка:** перед массовой генерацией — 1–2 пробные картинки; потом лист кадров; неудачная —
  `--redo <ключ>` (новый seed), подчистка — `erase` в библии + `--rekey`; принять как есть — `--accept`;
- **цена:** $0.018 за картинку; постановка ≈ 60–75 картинок ≈ $1.1–1.4;
- **кто:** скрипт; человек отбирает.

### 7. Таймлайн — `make timeline` (`F=horizontal`, `L=ru`)
- **вход:** раскадровка, время речи (озвучка; без неё — оценка по темпу), библия, ассеты;
- **выход:** `build/timeline[-формат][-язык].json` — у каждого кадра полный список элементов, камера, фокус, свет;
  субтитры по словам; паузы режут дубли между предложениями;
- **кто:** скрипт.

### 8. Звук — `make sound`
- **вход:** таймлайн, `storyboard.json → sound` (фоны по декорациям, музыка от кадра до кадра, шумы в кадрах);
- **выход:** `build/sound[-…].wav` — голос + фон (дождь, ветер, часы, сверчки…) + музыка (шкатулка, гул, орган),
  фон приседает под голос (`bed_duck`), затухание в конце (`fade_out`), громкость −16 LUFS;
- **кто:** скрипт (синтез без сэмплов); человек слушает.

### 9. Просмотр и рендер
- `make preview` — плеер без рендера (кадры + звук), `&shot=…`, `&debug`;
- `make video` / `make video-demo` — mp4 (GPU, если есть) + версия для соцсетей; `make youtube F=horizontal` —
  `.srt` и главы.

### 10. Сайт — `make site` → `dist/` (`docs/site.md`)
- **вход:** `site.json` (рассказы, озвучки по языкам, видеоверсии = постановки), всё выше;
- **выход:** страницы EN/RU, чтение с подсветкой и MP3, видео в браузере (таймлайны, слои webp, звук m4a, постеры);
- **проверка:** `make serve`; пересобирается только изменившееся (звук — дольше всего);
- **дальше:** `make deploy` (`deploy/README.ru.md`).

## Кто что решает

| решение | сейчас | в автоматическом пайплайне |
|---|---|---|
| рассказ, голос, стиль, режиссёр | человек | человек (конфиг) |
| перевод | LLM, человек читает | LLM, человек утверждает |
| библия, раскадровка | агент по навыкам `paper-film`, `storyboard` | LLM по схеме + валидатор; человек утверждает |
| отбор картинок | агент и человек по листам | автопроверки + человек |
| камера и свет по стоп-кадрам | агент смотрит листы и правит | vision-модель → JSON-правки → пересборка (необязательно) |
| звук, музыка | агент в раскадровке, человек слушает | LLM-черновик по сценам или своя музыка файлом |

## Автоматизация (план)

Всё, что делал агент, — это вызовы API и творческие решения, выразимые промптом с проверкой. Скрипты:

1. **`engine/bible.py`** — анализ текста (LLM, по схеме `bible.json`; образец — `illustrate.analyze_section`
   в mountain-rock): мир, герои с каноном, позы из сцен, декорации слоями с позициями по типовой сетке декорации
   (задник z −80…−100, стена с проёмом z −30, пол, предметы на столе).
2. **`engine/board.py`** — черновик раскадровки сценами (1–3 абзаца на запрос, с контекстом прошлых сцен):
   LLM получает текст с id предложений, библию, режиссёрский профиль (`directors/*.json → language`), словарь камер
   и эффектов и готовую раскадровку как образец → JSON; **валидатор** (`timeline.build`: ошибки реплик, камер, ассетов;
   длины планов по режиссёру) возвращает ошибки в LLM до чистого результата.
3. **`engine/review.py`** — проверки кадров без модели (яркость, доля пустого кадра, герой у края, видимый край
   слоя-декорации) и необязательный проход vision-моделью по листу стоп-кадров.
4. **`make film S=<постановка>`** — подряд: prepare → translate → voice (все языки) → bible → board → assets
   (пробные 2 → стоп для утверждения → все) → timeline (все форматы и языки) → sound → stills (стоп) → site.
5. Админка — утверждение библии, раскадровки, отбор картинок (сейчас — только просмотр: `make admin`).

Цена полного прогона рассказа такого размера: перевод ≈ $0.2, озвучка ≈ $0.25 на язык, библия и раскадровка
≈ $0.3–0.5 (LLM), ассеты ≈ $1.2 на постановку — **около $2–3 за рассказ с одной постановкой**.
