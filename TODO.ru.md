## 6. Позже: пайплайн без агента

Всё, что делал агент (Claude Code), — либо вызовы API, либо творческие решения, которые можно выразить промптом
с проверкой. Для следующих рассказов тот же путь может стать шагами `make`:

| этап | сейчас | без агента |
|---|---|---|
| текст, перевод | `make prepare`, `make translate` | ✓ уже скрипты |
| библия: мир, герои, позы, декорации | пишет агент | `engine/bible.py analyze`: LLM по тексту → JSON по схеме; позы — из сцен раскадровки |
| раскадровка | пишет агент | `engine/board.py draft`: LLM получает текст с id предложений, библию, словарь камер/эффектов и готовую раскадровку как образец → JSON; **цикл с валидатором** (ошибки `timeline.build`, длины кадров, камеры, существующие ассеты) возвращает ошибки в LLM до чистого результата |
| ассеты, озвучка, звук, рендер | ✓ `make` | ✓ (музыкальные кюи — черновик LLM по сценам или своя музыка файлом) |
| контроль качества | агент смотрит листы кадров, правит камеры и свет | `engine/review.py`: автоматические проверки (средняя яркость, доля пустого кадра, главный герой обрезан краем) + необязательный проход vision-моделью → JSON-правки → пересборка |

Человеку остаётся: выбрать рассказ и голос, утвердить библию и раскадровку, посмотреть лист кадров, «оставить /
переделать». Полный прогон рассказа такого размера ≈ $2–3 (перевод ≈ $0.2, библия + раскадровка ≈ $0.3–0.5,
≈ 75 картинок ≈ $1.5, озвучка ≈ $0.2). Шаги: `bible.py` → `board.py` (по сценам, 1–3 абзаца на запрос, с предыдущими
сценами как контекстом) → `review.py` → `make film S=<рассказ>` (останавливается на стоп-кадрах для утверждения) →
простая админка для утверждения библии и раскадровки.
