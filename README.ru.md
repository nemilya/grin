# Рассказы Александра Грина: озвучка, видео, сайт

[English](README.md) · **Русский**

Движок, который превращает рассказ в озвучку и видео в нескольких стилях, и сайт **grin.nemilya.me**, где их
читают, слушают и смотрят. Рассказ переводится (EN), озвучивается на русском и английском и разыгрывается на
WebGL-сцене (three.js): слои по глубине, свет, глубина резкости, камера; кадры считаются из времени — прямо
в браузере на сайте или снимаются в mp4. Первый рассказ — «Мат в три хода» (1908, `stories/mate-in-3`) в двух
постановках: **бумажный театр** (вырезки на столе под лампой) и **в духе Тарковского** (`stories/mate-in-3-tarkovsky`:
фотографичные слои, длинные планы, дождь, туман, паузы); у каждой — вертикаль 9:16 и горизонталь 16:9.

```bash
make site && make serve     # сайт → http://127.0.0.1:8730/  (make deploy — на сервер)
make admin                  # админка (просмотр): ассеты, листы героев, раскадровка, озвучка → http://127.0.0.1:8740/admin/
make preview S=mate-in-3-tarkovsky F=horizontal L=ru   # плеер постановки: 16:9, на русском
```

Весь цикл — новая машина → работа → сборка → деплой на сервер — [ниже](#полный-цикл-от-клона-до-сайта).

Движок продолжает `nemilya/mountain-rock` (текст, перевод, озвучка, сайт с чтением и подсветкой) — модули
оттуда перенесены и приспособлены.

## Локальная установка

Один раз (macOS; на Linux — то же через свой пакетный менеджер):

```bash
brew install python ffmpeg node          # Python 3.10+, ffmpeg, Node 18+
python3 -m pip install numpy pillow      # или в venv: python3 -m venv .venv && . .venv/bin/activate && pip install numpy pillow
make setup                               # проверит всё это, npm install, скачает Chromium для захвата, создаст local.mk
make media-pull                          # картинки и озвучка из nemilya/grin-media (≈ 0,3 ГБ, см. «Медиа»)
```

Браузер для захвата — Chromium Playwright (закреплён `playwright@1.59.1`: более новые не ставят Chromium
на macOS 13); если его нет — берётся установленный Google Chrome.

`make setup` создаёт `local.mk` из `local.mk.example`. В нём:

```make
OPENROUTER_API_KEY = sk-or-…     # нужен только для генерации: перевод, картинки, озвучка
```

Видеокарта выбирается сама: захват сначала пробует GPU и, если его нет, переходит на программный
SwiftShader (≈ 1 с/кадр при 720×1280). Задать явно — `CAPTURE_GL = gpu` или `cpu` в local.mk.

Проверка и первый ролик:

```bash
make status          # что готово по этапам
make video-demo      # финал (с кадра s12a), 1080×1920 → out/mate-in-3/mate-in-3-demo.mp4 (+ -share.mp4)
make preview         # плеер без рендера — кадры + голос + музыка: http://127.0.0.1:8720/stage/?story=mate-in-3
make preview F=horizontal   # то же для 16:9 (&tl=horizontal); &debug — рабочий свет, &shot=s05g — с кадра
```

В начале рендера печатается строка `WebGL: … — видеокарта / программный рендер`: имя видеокарты
(Apple M…, NVIDIA…) — GPU; `SwiftShader` — программный.

После рендера рядом с мастером (1080×1920, высокий битрейт — для монтажа и архива) появляется
**`…-share.mp4` — версия для соцсетей**: 720×1280, H.264, ≈ 3,5 Мбит/с, AAC 128k, faststart — Reels, Shorts,
TikTok, Telegram принимают её без перекодирования (≈ 25 МБ на минуту). Для готового файла —
`make share FILE=out/mate-in-3/mate-in-3-demo.mp4`; не делать — `--no-share`.
Всё сгенерированное уже есть — **ассеты и озвучка всех постановок** лежат в репозитории медиа (`make media-pull`),
так что ключ для рендера не нужен: `make video` (вертикаль, 18,7 мин) и `make video F=horizontal`.

## Этапы (харнес)

Каждый этап пишет файлы в `stories/<история>/`, следующий читает их; у генерируемого — отпечаток
(текст + настройки + референсы): поменялось что-то выше — ниже становится «устаревшим» (stale), остальное
не трогается. `make status` показывает всё сразу.

| | этап | команда | файлы |
|---|---|---|---|
| 1 | текст: абзацы → предложения → слова | `make prepare` | `prepared/ru.json` |
| 2 | глоссарий и перевод по абзацам (те же id) | `make translate` | `glossary.json`, `translations/en.json`, `prepared/en.json` |
| 3 | библия: мир, герои и их позы, декорации, предметы | вручную / агент / LLM (см. next-session) | `bible.json` |
| 3 | раскадровка: сцены → кадры, привязанные к предложениям | вручную / агент | `storyboard.json` |
| 4 | ассеты: листы героев → вырезки поз (хромакей → альфа) → декорации | `make assets-used` | `assets/`, `assets/assets.json` |
| 5 | озвучка по абзацам с проверкой распознаванием | `make voice` | `voicings/<id>/`, `overrides/en.json` (манера) |
| 6 | таймлайн: время кадров из речи, состояние сцены, субтитры | `make timeline` | `build/timeline.json` |
| 7 | звук: голос + фон + музыка-синтез + шумы | `make sound` | `build/sound.wav` |
| 8 | кадры: стоп-кадры раскадровки / ролик (+ версия для соцсетей) | `make stills` / `make video` | `out/<история>/` |

Пока ассета нет, сцена рисует **заглушку** (цветной силуэт с подписью), пока абзац не озвучен — время
**оценивается** по темпу: раскадровку можно смотреть и править с первого дня, всё дальше только уточняет.

## Форматы: вертикаль и горизонталь

Один фильм — несколько форматов (`story.json → formats`). Основной — вертикаль 9:16 (`film`); горизонталь
16:9 для YouTube — `formats.horizontal` со своей раскадровкой `storyboard-16x9.json`, которая **наследует**
основную (`"extends": "storyboard.json"`) и меняет только камеры (`cams` — те же имена, кадрирование под 16:9)
и отдельные кадры (`shots`: правки по id, `drop` — убрать, `add` — добавить). Перевод, озвучка, звук, ассеты,
реплики и состояние сцены — общие; субтитры раскладываются под формат (в 16:9 — внизу, до 84 знаков).

```bash
make video-demo F=horizontal     # демо 1920×1080 → out/mate-in-3/mate-in-3-horizontal-demo.mp4 (+ -share.mp4, 1280×720)
make video F=horizontal          # фильм целиком в 16:9
make youtube F=horizontal        # субтитры .srt и главы по сценам для описания ролика
make stills F=horizontal         # стоп-кадры для проверки композиции
```

Предпросмотр формата: `http://127.0.0.1:8720/stage/?story=mate-in-3&tl=horizontal` (после `make timeline F=horizontal`).
Для YouTube можно не вшивать субтитры, а загрузить `.srt`: `"subtitles": {"burn": false}` в `formats.horizontal`.

## Языки ролика

Озвучки по языкам — `story.json → film.voicings` (`narrator-en`, `narrator-ru`, тот же голос Charon). Раскадровка одна
(реплики — по предложениям английского перевода); ролик на другом языке — `L=ru`: голос и субтитры русские, реплики и
паузы перенесены по доле текста абзаца (паузы — на ближайший промежуток между русскими предложениями).

```bash
make voice L=ru                                  # озвучка недостающих абзацев на русском (≈ $0.25)
# длинный абзац, на котором TTS сбоит (пустой звук, finish reason OTHER), — куски короче: overrides/ru.json → {"story-040": {"max_chars": 220}}
make timeline S=mate-in-3-tarkovsky L=ru         # build/timeline-ru.json (F=horizontal L=ru → timeline-horizontal-ru.json)
make preview S=mate-in-3-tarkovsky L=ru
```

## Раскадровка

`storyboard.json` — сцены и кадры. Кадр начинается на реплике `"at": "018.13"` (абзац 18, предложение 13;
`"+0.5"` — с середины предложения) — так кадры привязаны к тексту, а не к секундам, и переживают переозвучку.
Состояние сцены переходит из кадра в кадр: кадр указывает только изменения.

```json
{"id": "s05g", "at": "018.17", "cam": "win-street", "push": 3, "focus": {"on": [0, 15, -27], "f": 1.6},
 "cast": {"woman-baby": {"card": "woman-baby/walking", "pos": [-24, 8, -27],
                         "move": {"to": [24, 8, -27], "ease": "linear"}, "fx": {"bob": 0.25}}},
 "sfx": [{"name": "rustle", "at": 0.1}], "note": "красный кумачовый платок"}
```

- **элементы** (`cast`): `card` — ассет (`герой/поза`, `декорация/кусок`, `prop/…`), `pos` [x, y, z] в см
  (y — вверх от пола сцены, z — к камере, карточка стоит нижним краем), `rot`, `move` {to, rot_to, start,
  end, ease} или маршрут `move.keys` [[доля кадра, [x, y, z]], …] (вышел из-за портьеры, постоял, ушёл),
  `fx` — кукловодные эффекты: `walk` (шаг: карточка покачивается, не подпрыгивая), `bob` (подпрыгивание —
  бег), `jitter` (дрожь руки), `sway`,
  `breathe`, `wobble`, `twinkle` (звёзды), `flicker`; `glow` — отсвет; `parts` — углы шарниров
  (`[[доля кадра, градусы], …]`); `shadow_only` — только тень; `null` — убрать; `{"reset": true}` — кусок
  декорации на место;
- **камера**: `cam` (именованная точка из `cams`), `push` (наезд, см), `drift`, `hand` (сила «ручной» камеры,
  0 — штатив);
- **фокус**: `on` → `to` (элемент или точка) в доли `at`, `f` — «диафрагма» (больше — мельче ГРИП), `f_to`;
- **свет**: пресет декорации или `preset`, `k`/`k_to`/`ramp`, `angle_to`, `target_to`, `warm`,
  `fx` — `swing` (лампу задели), `heartbeat`, `breath`; переход `in`: `cut` / `dip` (свет гаснет и
  загорается — смена места) / `fade`;
- **звук**: `sound.beds` (фон по декорациям), `sound.music` (от кадра до кадра: `drone`, `musicbox` с нотами
  `"D4+A4:1 D5:1 …"`), `sfx` в кадре (`click`, `hum`, `breath`, `thump`, `rustle`, `heartbeat`).

## Ассеты

`assets.py`: промпт = стиль (`styles/paper-theatre.json`: гуашь и карандаш на картоне, белая кромка ножниц)
+ канон героя из библии + поза. Сначала **лист героя** (разворот 4 вида) — он идёт референсом во все позы:
лицо и костюм узнаваемы. Вырезки — на хромакее #00FF00, ключ по «зелёности» с мягким краем и подавлением
ореола, обрезка по силуэту. Seedream 5.0 Flash, $0.018 за картинку; финал (26 картинок) — $0.45.
Вырезки хранятся в WebP без потерь (те же пиксели, что PNG, ≈ 45 % объёма). Исходники до ключа — `assets/raw/`,
прежние варианты — `assets/takes/` (оба только локально).

## Сцена и рендер

`stage/` — статическая страница (three.js 0.160 лежит в `stage/vendor`, без CDN): карточки на изогнутой
бумаге с фактурой и тенями по альфе, свет лампы (spot) + абажур в кадре + заполняющий, глубина резкости
(своя: глубина с учётом альфы вырезок, боке по золотой спирали), виньетка, зерно, субтитры. Любой кадр
считается из времени t — `tools/capture.mjs` снимает кадры Playwright'ом и пишет в ffmpeg (H.264 + AAC).
Видеокарта выбирается автоматически (Apple M2 — ≈ 0,07 с/кадр при 1080×1920); без неё — программный SwiftShader,
≈ 1 с/кадр при 720×1280. Кодек на macOS — аппаратный `h264_videotoolbox` (процессор почти не занят); `COOL=1` —
режим без перегрева (низкий приоритет ffmpeg, 2 потока, паузы между кадрами).

## Медиа: второй репозиторий

Код, тексты, переводы, библии, раскадровки и манифесты — здесь; картинки и озвучка (`stories/**/*.webp|jpg|opus`) —
в [nemilya/grin-media](https://github.com/nemilya/grin-media), по тем же путям. Его git-папка — `.media.git/`,
рабочая папка — эта же: файлы лежат там, где их ждёт движок. `media.rev` (одна строка, в git) — какой коммит медиа
нужен этому коммиту кода: любой коммит воспроизводим (`git checkout …` → `make media-pull`).

```bash
make media-pull      # медиа из media.rev (LATEST=1 — последние в ветке медиа)
make media-push      # после генерации: закоммитить и запушить изменённые медиа, записать media.rev (закоммитить вместе с JSON)
make media-status    # скачаны ли, что изменено локально, что не запушено
```

- ветка медиа называется как ветка кода (`main` → `main`); разошлись (запушили параллельно) — сливаются сами;
- пока медиа из `media.rev` не скачаны, `make assets`, `make voice`, `make site` не запускаются (иначе свежий клон +
  `make assets` = перегенерация всего фильма за деньги); обойти — `MEDIA_CHECK=0`;
- хук `pre-push` (`tools/hooks`, ставят `make setup` и `make media-pull`) не пускает код, чей `media.rev` не запушен.

## Полный цикл: от клона до сайта

**1. Новая машина (один раз).**

```bash
git clone https://github.com/nemilya/grin && cd grin
make setup            # проверит python/numpy/pillow/ffmpeg/node, npm install, Chromium, создаст local.mk, поставит git-хук
make media-pull       # картинки и озвучка из media.rev (≈ 0,3 ГБ, от секунд до минуты)
make status S=mate-in-3
```

В `local.mk` (не в git; можно перенести из старой папки): `OPENROUTER_API_KEY` — только для генерации;
`DEPLOY` и `SITE_URL` — только для публикации (шаг 4).

**2. Сервер для сайта (один раз).** nginx раздаёт папку, https через certbot, DNS — [deploy/README.ru.md](deploy/README.ru.md)
(готовый `deploy/nginx.conf`). Сайт статический: всё, что ему нужно, — в `dist/`.

**3. Работа: новый рассказ или правки** (на маке или в облачной сессии Claude Code):

```bash
git pull && make media-pull                    # свежий код и медиа той версии, что в нём записана
# … текст → перевод → библия → раскадровка → make assets-used / make voice (платно) → make timeline → стоп-кадры
make media-push                                # картинки и озвучка → grin-media; media.rev добавлен в коммит
git add -A stories/<рассказ> && git commit -m "…" && git push   # хук проверит, что медиа запушены
```

На сайте рассказ появляется, когда он записан в `site.json` (`stories`: его `voicings` и `videos`).

**4. Публикация** (на маке — деплой идёт по ssh, которого в облачной сессии нет):

```bash
git pull && make media-pull     # ровно то, что в main
make site                       # → dist/; первая сборка ≈ 30 мин (звук видео для каждой постановки и языка),
                                #   дальше — только изменившееся
make serve                      # посмотреть: http://127.0.0.1:8730/
make deploy-dry                 # что уйдёт на сервер
make deploy                     # залить → https://grin.nemilya.me
```

`make deploy` заливает ровно ту сборку, что вы видели, и не зальёт устаревшую (после `make site` поменялись тексты,
озвучка, раскадровки, ассеты, `site.json`, сцена). Подробности — [deploy/README.ru.md](deploy/README.ru.md).

## Устройство

```
stories/<история>/
  story.json            источник, язык и формат ролика, стиль, озвучка
  prepared/ ru|en.json  текст: абзацы, предложения, слова (id абзацев общие для языков)
  glossary.json  translations/en.json   перевод
  bible.json  storyboard.json           постановка
  assets/  voicings/  overrides/        сгенерированное (с отпечатками; файлы медиа — в grin-media)
  build/                таймлайн и звук (не в git)
engine/   config, text, prepare, translate, llm, openrouter, voicing, align, audio, pricing — из mountain-rock;
          assets (Seedream + ключ), timeline (раскадровка → кадры), sound (синтез и сведение), __main__ (харнес)
stage/    index.html (предпросмотр + API захвата), js/stage.js, js/paper.js (бумага, заглушки, процедурные
          карточки), js/post.js (фокус, плёнка), fonts/ (Source Serif 4, OFL), vendor/three
tools/capture.mjs       стоп-кадры и ролик
styles/   стили ассетов
```

`make test` — тесты без сети; `make check` — тесты + синтаксис JS.
